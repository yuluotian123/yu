# Original author cloud implementation

Source: [新杨XIYAG article](https://zhuanlan.zhihu.com/p/660806535), [GitHub repository](https://github.com/xinyangaa/Unity_URP_Genshin_Impact_Programmed_Skybox/tree/ef1bd4c6fa486977a323c3badaba5740feae1d55). Pinned commit: `ef1bd4c6fa486977a323c3badaba5740feae1d55`.

## Active resources

`spacelevel/EnvironmentRig/OriginalClouds` contains BaseClouds, HighClouds and SecondaryClouds MeshInstance3D nodes from `assets/scenes/environment/reference_clouds.tscn`. No cloud nodes, meshes or textures are created at runtime.

The active FBX and PNGs in `assets/environment/reference_clouds` are byte-for-byte copies, checked against Git blob hashes in `source_manifest.json`. `original_cloud_mesh.res` is the Godot importer output of the author's `cloud.fbx` mesh (80 vertices, 20 quads, original UV2). `78678.png` is the exact RGBA image referenced by the source base-cloud material, retaining its sRGB import flag, mipmaps and clamp wrap. There is no synthetic SDF, blur, resizing or tile repacking. The original noise PNG is also used at its full 2048² resolution.

`cloud.gdshader` preserves the original `Cloud.shader` fragment equations: UV2; twice-applied noise tiling; `_Time.x * 0.05`; scalar positive 0–0.03 UV disturbance; one-sided 0.08 SDF transition multiplied by A; squared light-direction weight; four-color mixing through R plus G edge lighting. Material noise tiling is (0.3, 0.3). The exact Unity shader and material metadata are retained beside the port for comparison.

`base_timeline.tres` contains all 22 material curves from clip `1387710026462685712`, bound in the source scene to the base cloud. Keys and unweighted Hermite tangents are preserved; the 0–4 time domain is normalized to 0–1, scaling tangents by 4. In particular, the first SDF value is 0.041 and the last is 0.050, without the previous endpoint repair. The high and secondary resources each retain their own 22 source material curves, now bound to separate scene-local materials. `000001EEA8FB26F8.png` is their unmodified original atlas.

## Godot integration differences

- HLSL is translated to Godot spatial shader syntax. Clouds use unshaded ALBEDO, alpha blending and no depth writes; the source's `ZWrite On / ZTest NotEqual` cannot be carried into the game's reversed-Z sky background behavior. The shader puts clouds at far depth so scene geometry remains in front.
- Vertex projection is centered on the active game camera, using its real perspective projection or the existing orthographic sky FOV and pitch. The GPU projection Y sign is preserved. Original cloud UVs and geometry stay intact. The author's reference camera height (-14) is retained as a view offset.
- The cloud node uses the saved Unity scene position (0, 0, 0). Its example-specific animated position (-119.6 Y) is not applied, because it places the entire layer below this level's playable view. This is a scene integration choice, not a change to the mesh or shader equations.
- All three cloud layers receive the same perspective/orthographic projection and current Sun/Moon directions. Their materials are Local To Scene and independent of each other.
- Noise time is driven by the existing deterministic world clock rather than Unity time. SDF animation defaults to 1.6 game hours, equal to the author's 80-second period at the default 20-minute day. Original color and SunMoon curves map sunrise/noon/sunset/midnight to the existing 20-minute game day. Pause, GM time changes and save/restore keep working.

## Completed layers and rotations

`rotation_timeline.tres` contains the source group, high-layer and secondary-layer Euler-Y curves. Group and secondary go from 1 to 361 degrees with linear tangents; high uses the original zero endpoint tangents. The normalized Curve tangents are multiplied by four. `CloudRotationPeriodHours` and `CloudEvolutionPeriodHours` each default to 1.6 game hours; `CloudNoisePeriodHours` defaults to 8 game hours. All phase sampling goes through `TimeOfDayProfile.SampleCloudTime(totalGameHours)` in both gameplay and editor. At the default 20-minute day these retain the previous 80-second rotation/SDF and 400-second noise periods. Changing day length changes the world-clock rate without repositioning clouds at a fixed calendar instant. Godot yaw is negated for Unity's handedness. All layers use absolute world time, preserving pause, seek, rewind, game speed and save/restore.

All layers now inherit only the common `GroupYaw` wind pivot. `HighYaw` and `SecondaryYaw` remain archived in the source resource, but are not applied: combining group and child tracks made secondary clouds rotate at twice the base rate and made high clouds accelerate/decelerate relative to the base. Local scene-authored mesh orientations stay fixed throughout the cycle. The missing FBX's 179.5-degree import orientation and example-specific offsets are not applied.

The uploaded FBX has GUID `6cc1303ea41d42846945248ef433ee35`, matching the original base cloud. The example's high and secondary mesh GUID `4e842a0dab424954fbbe40e4d81b5a3d` is absent from both resource-upload commits (`ac163529`, `4144b98e`) and the latest tree. All 16 public forks listed on 2026-10-06 retained the upstream push timestamp and repository size; no newer resource upload was found.

To complete the requested layers, `reconstructed_high_mesh.res` and `reconstructed_secondary_mesh.res` were baked offline. These are **reconstructed meshes, not recovered author models**: 28 high and 14 secondary upright quads in staggered rings, preserving a 2:1 plane aspect for the original 512x256 atlas cells. The baker derives the ring radius and up vector directly from the original base mesh (including its approximately 0.5-degree tilt); higher rings differ in height, not in how they face the camera. Radial-facing planes and random roll are removed, so upper and lower clouds share the same foreshortening convention as well as the same shader projection. Source RGBA textures, noise and per-layer animation curves are unchanged. All three materials enable `bound_atlas_cell` to clamp the disturbed UV to its own 2x4 atlas cell and fade the last 0.012 UV at the border, preventing neighboring-cell slivers (also observed on the original base FBX with the provided noise). This is an explicit sampling-boundary correction; no source texture or FBX bytes are changed. It can be disabled on each material to inspect the unbounded original formula.

The reconstructed meshes are saved resources. The one-off baker has been removed; scene nodes, meshes and materials are loaded directly from the project.

Editor cloud placement is sampled from `StartDay * 24 + StartHour`, with no independent elapsed-time counter. Scrubbing the start date/time gives the same cloud rotation, shape, noise and color phase as seeking that date/time in the game. Runtime motion uses the world clock/GM, including pause, speed zero, speed changes and rewind. Legacy serialized second-based period keys are converted using the original 20-minute-day reference; the obsolete editor animation toggle is accepted and discarded.

The material's original noise GUID `efdab6692df1af443b3b1b6d4996d2ed` remains unresolved. All layers use the repository's full-resolution `Noise_091.png` rather than leaving an empty binding. This fallback and the reconstructed layouts prevent claiming an exact visual reproduction of the article GIF.
