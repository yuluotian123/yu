# RE:BODY · 废土机器人

单文件离线俯视角动作游戏。主角通过夺取义体教徒的肢体重组自己，穿越三个区域，寻找最后的巨像。

## 启动

双击 `启动游戏.cmd`，或用浏览器打开 `index.html`。更新后刷新页面。无需安装依赖或联网。

开发预览可执行 `node serve.mjs`，访问 <http://127.0.0.1:4173/>。

## 操作

| 输入 | 功能 |
| --- | --- |
| WASD / 方向键、鼠标 | 移动、瞄准 |
| 左键 / 长按 | 左臂近战击倒；再攻击倒地目标会补刀 |
| 右键 / 长按 | 标准右臂拳击；安装炮臂后射击 |
| F | 站在倒地目标或未拆取尸体的躯干上时，进入处决选择 |
| 点击部位 / 1–4 | 选择左臂、右臂、左腿、右腿 |
| Q / E | 分别拔下、投掷左臂 / 右臂 |
| X | 取回自己投出的上肢，或使用解锁后的出口 |
| 空格 | 闪避；强化机足为冲撞 |
| Z | 安装殉刃义臂后释放旋刃 |
| Esc | 取消选肢，或暂停 / 继续 |
| R / M | 重试本关 / 声音开关 |

触屏提供摇杆、自动瞄准及独立的动作按钮。右侧机体面板上方可切换全屏，页面失焦会自动暂停。

## 晶体管监视器界面

主界面只保留游戏屏幕、右侧机体和底部按键。屏幕使用复古绿色磷光、扫描线、玻璃反光、暗角和硬件边框；战斗中的血液和各类组件仍保留可区分的颜色。机体面板只显示当前部件名与耐久，核心生命以三格指示灯表示，不再显示能力说明、冷却提示、章节统计和剧情面板。开始、暂停、死亡和关卡切换界面也已精简。

机体面板下方显示机器人三定律，其中涉及的对象名称均以乱码呈现。选肢界面只保留部位、数字键、耐久及时间倍率，战斗交互提示缩为 F / X。减少动态效果的系统设置会关闭界面过渡；无外部字体或贴图依赖。

## 近身战斗与组件损坏

开局拥有完整的标准双臂和机足。普通站立近战距离为 43，强化刀臂为 61；爬行时分别为 28 和 36。挥击特效与判定共用范围，攻击需要朝向目标。旋刃的范围也已缩小。

敌人近战命中会扣除 **2 点核心**；枪手和守门者的弹丸造成 **3 点核心伤害，枪击一次致命**。命中同时随机选中一个仍可用的组件，**一击炸毁**。被击中的位置有爆光、金属碎片、火花、短暂停顿和破损外观，不再逐次扣减耐久。已投出的上肢和已报废组件不会再次被选作损坏目标；没有可用组件时直接损伤核心。

报废上肢不能攻击、开炮或释放技能。炸毁后仍附着的破损上肢可用 Q / E 拔下投掷：命中站立或倒地敌人会爆炸，直接击杀范围内可触及的敌人，包括装甲目标；未命中、撞墙或落地的上肢可取回。完整上肢投掷命中普通敌人会击倒，对装甲敌人削甲。投出后模型对应上肢消失，取回保留类型和耐久，不修复核心、不加分。

机足归零后，玩家模型失去下肢，低伏拖行，速度从 300 降至 105，近战范围缩短，无法闪避或冲撞。安装新的腿部后恢复站立。攻击和强化技能仍会消耗组件耐久。

## 敌人的致命性

- 刀徒以 285 的速度追击，行者为 365，行者能够追上正常奔跑的玩家。近战前摇缩至 0.12–0.15 秒，出手时朝已锁定的方向短促前扑，连续两次命中即可摧毁完整核心。
- 枪手和守门者扩大警戒范围，约 0.2–0.26 秒完成举枪，弹丸速度为 940–1000。枪手会预判玩家移动，在开枪前最后 0.08–0.1 秒锁定方向；弹丸出膛后不会追踪玩家，墙体仍能挡住枪线。
- 射击、近战、击倒、击杀和爆炸会惊动附近敌人。枪声可穿过墙体引来增援，爆炸的影响范围更大。
- 受击后的保护从 1 秒缩至 0.18 秒，处决结束后的保护为 0.2 秒。取消选肢也只提供极短保护，需要立即攻击、闪避或转移。处决过程本身仍然免伤。
- 更亮的瞄准线、枪口焰、弹道和近战挥臂表现攻击方向。利用掩体、侧闪、抢先击倒、Q / E 投臂打断，R 可以立即重试。

## 处决条件和姿态

流程为 **击倒 → 移到目标躯干上 → 按 F → 拉近镜头、时缓选肢 → 处决与接入 → 恢复战斗**。

仅仅靠近目标不能触发。玩家必须已经站在目标的身体范围内；F 和触屏按钮使用相同判定。选肢时玩家原地半透明显示，使目标的身体和四肢清晰可见，不会把玩家挪到目标旁边。

普通敌人被近战击倒后停止攻击，未继续攻击时 5 秒后起身。倒地时仍是存活敌人，出口保持封锁。守门者需先破甲。

**继续直接攻击倒地敌人会立即补刀。** 左右臂近战、射击、旋刃、投臂和强化冲撞均可触发，倒地的装甲目标也会直接死亡。补刀按攻击接触位置毁掉一处肢体，在断口喷出血液和碎片，留下原地持续存在的缺肢尸体；不会直接安装或掉落可拾取部件。尸体剩余完整部位仍可按 F 拆取一次，已毁坏部位不能选择。近战补刀仍受可用手臂、距离、朝向和墙体遮挡限制。选择期间背景保持 6% 速度，动画期间为 12%；玩家在选择与处决期间免伤。

- **有下肢：跨坐跪压。** 机器人骑跨在目标躯干上，双膝分开压住目标，抓紧后快速猛扯；约 0.8 秒完成。
- **无下肢：贴伏拖拽。** 不画跪姿和机足，机器人用肩胸抵紧目标，反复拉扯并向后拖身借力；约 1.2–1.3 秒完成。抓握、拉扯、身体姿态、后坐和声音均与有下肢时不同。

左臂解锁大范围近战与 Z 旋刃，右臂解锁贯穿脉冲，两条腿均可恢复强化机足。每次处决只接入选中的一个部件，并修复 1 点核心。目标擅长的部位耐久为 100%，其他为 75%；守门者各部位均为 100%。

## 一次处决与碎肢堆

**每个目标只能处决一次。** 扯离瞬间目标就变成血泊、碎肢和破碎护甲，不再保留可继续拆取的完整身体。碎肢留在原地，在本关持续存在；没有 F 提示，也不能再次选择、重复处决或获取其他部件。

普通射击、旋刃、冲撞或爆炸击杀不会自动掉落部件。这些尸体可能随机缺少部分肢体；玩家可以站到其身上执行一次拆取，选择实际仍存在的部位，随后同样变成不可交互的碎肢堆。常规死亡的取肢不会重复计算击杀。

各类敌人的倒地和普通尸体保留各自服装、头部和护甲，比例与原体型一致。尸体、碎肢及血迹在重试或换关时清理。剧情芯片与记忆面板已移除。

## 关卡与验证

三个手工关卡共 22 名敌人。肃清后在出口按 X 前进，保留组件类型、耐久及已缺失上肢状态。R 恢复本关检查点。最高分和声音设置保存在当前浏览器中，不上传数据。

运行 `node verify.mjs` 执行 **56 项检查**，直接测试交付 HTML 的逻辑，包括一击炸毁、短近战范围、身体重叠触发、两种处决姿态与耗时、一次处决限制、碎肢持续存在、投掷爆炸、爬行、暂停、检查点与通关，倒地补刀、缺肢尸体后续拆取、补刀距离和朝向限制，以及开局致命性、枪击即死、快速近战、预判与锁定瞄准、枪声引敌和行者追击。
