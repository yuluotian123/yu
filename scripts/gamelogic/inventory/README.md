# 武器行囊

B 或右下角背包按钮打开；B / Esc / 右上角 × 关闭。点击物品格查看详情，使用“装备武器”“切换为当前武器”或“卸下武器”操作。左侧装备卡的减号也能卸下武器。

按住鼠标左键拖动武器，松开即放置：

| 拖拽方式 | 结果 |
| --- | --- |
| 行囊格 → 行囊格 | 移到空格；目标格有武器时交换位置，保留空格布局。 |
| 行囊格 → 装备槽 | 装备到指定槽；已装备武器会调整或交换槽位。 |
| 装备槽 → 装备槽 | 移动或交换两槽，当前手持武器跟随物品保持不变。 |
| 装备槽 / 角色预览 → 行囊格 | 卸下并移到目标格，仍禁止卸下最后一把武器。 |
| 武器 → 角色预览区 | 装备并设为当前武器，同步角色外观。 |

拖动时显示武器图标和名称，绿色边框表示可放置，红色边框表示拒绝。拖到界面外、无效区域或关闭窗口均取消操作，物品保持原位。动作期间不能拖拽整理；武器冷却保留。装备到备用槽和交换装备位置不主动改变手持武器，替换当前槽中的武器时才切换为新武器。

初始拥有大剑、太刀，两把均已装备，默认持有大剑。行囊默认 12 格，以武器 ID 去重；装备槽保存物品引用，装备或卸下不增减物品所有权。卸下的武器在行囊中标记为“未装备”，Q 只遍历已装备的槽位。最后一把武器禁止卸下，界面按钮与组件 API 都执行此限制。卸下当前武器时自动持有另一把。

攻击或冲刺期间暂时禁止整理装备；原有 Q 切换仍可排队到收招结束。卸下、再装备保持原能力实例与冷却。打开行囊屏蔽玩家移动、跳跃、攻击和 Q；关闭后清空输入缓存，并留出 0.15 秒防止关窗点击穿透。

- `InventoryComponent3D`：EC 物品所有权、窗口生命周期和模态输入控制；Player 的 `StartingWeapons` 配置初始物品。
- `WeaponEquipmentComponent3D`：两个固定装备槽；`EquipWeapon` / `UnequipSlot` / `RequestNextWeapon`。拖拽槽位通过 `activate: false` 保留手持武器身份。
- `InventoryWindow`：通过现有 `UIModule + UIWindow + SceneHandle` 加载窗口；原生 Control、木棕色方形描边、米色纸面、琥珀金选中与灰绿装备标记。武器图标为 32×48 SVG 像素轮廓，角色预览复用实际低像素精灵。
- CharacterGraph：`player_inventory`（B）→ `InventoryComponent3D.ToggleInventory`。窗口开启后 B / Esc 由组件处理关闭，避免角色输入被屏蔽后无法退出。
- `StandaloneModuleDriver`：F6 直接运行关卡时推进已有模块；正常入口有 RootModule 时不重复更新。

角色存档 schema 5 保存 `inventory.weapon_ids` 和可选的 `inventory.positions`（武器 ID 到行囊格编号），装备侧使用 `loadout_version = 1` 和允许 null 的 `slots` 保留空槽。先恢复所有权与格子位置，再恢复装备，最后恢复能力冷却。旧档没有 positions 时按已有物品顺序排列；重复、越界的位置自动放到空格。schema 1–4 继续兼容；无效的全空装备恢复一把已有武器，保持至少持有一把的规则。

运行 Spacelevel 后按 B，检查物品拖拽、装备槽交换、最后一把武器保护、无效落点取消及关闭行囊后的输入恢复。存档格式与恢复顺序见[存档系统](../saves/README.md)。
